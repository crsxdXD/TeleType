# TeleType — бесплатное автодополнение для Telegram Desktop

**TeleType** — маленькая экспериментальная утилита для **Windows 10/11**, которая показывает подсказки продолжения фразы при наборе сообщений в стандартном **Telegram Desktop** и исправляет ошибки по горячей клавише. Работает *поверх* Telegram: это не бот и не Telegram-плагин.

**Никаких платных API и ключей.** Языковая модель запускается **локально** на компьютере через [Ollama](https://ollama.com/download/windows). TeleType отправляет запросы только на `127.0.0.1:11434` и запрещает HTTP-редиректы. После первой загрузки модели интернет для генерации не нужен.

## Возможности

- **Подсказка**: напечатай не меньше 8 символов и остановись примерно на 0,9 секунды. Появится небольшое окно с возможным продолжением. **Ctrl+Alt+J** вставит предложенный фрагмент. Продолжать печатать тоже можно — подсказка исчезнет.
- **Исправление ошибок**: в поле набора Telegram нажми **Ctrl+Alt+G**. После обработки увидишь исправленный черновик; **Ctrl+Alt+J** заменит сообщение. Без подтверждения ничего не заменяется.
- **Три языка**: русский, украинский и английский. Модель старается сохранять язык, сленг, пунктуацию и стиль. Точность зависит от модели; самая маленькая модель иногда ошибается.
- **Значок в трее**: Help, Pause/Resume, Exit.
- **Никаких сообщений от имени пользователя**: программа не нажимает «Отправить».

Подсказка отображается в отдельном небольшом окне, **не как настоящий полупрозрачный текст внутри поля Telegram**. Это ограничение первой версии. Telegram Desktop использует собственный интерфейс, и совместимость с разными версиями ещё нужно проверить.

## Горячие клавиши (v0.2.1)

- **Ctrl+Alt+J** — принять подсказку или подтвердить исправление (только если подсказка видна).
- **Ctrl+Alt+G** — исправить грамматику и орфографию черновика.
- **Tab** и **Shift+Tab** — остаются за Telegram, TeleType их не перехватывает. Они также сбрасывают устаревшие подсказки.
- **Esc** — закрывает подсказку и, как обычно, передаётся Telegram.
- **AltGr / правый Alt** — не считается хоткеем: ввод символов на раскладках с AltGr не должен запускать AI.

В стандартной таблице клавиш Telegram Desktop по состоянию на ноябрь 2026 `Ctrl+Alt+J` и `Ctrl+Alt+G` не назначены. Но пользовательские сочетания могут отличаться: проверь **Settings → Chat Settings → Keyboard Shortcuts**. Программа намеренно игнорирует сочетания с Shift и Win, а при переключении чата сочетаниями Telegram сбрасывает устаревшую подсказку.

**Ограничение тестовой версии:** утилита пока распознаёт активное окно Telegram, но не определяет наверняка, что курсор стоит именно в поле ввода сообщения. Поэтому используйте функции только в поле черновика; не проверяйте их в поиске и настройках Telegram.

## Установка — бесплатно и локально

1. Установи [Ollama для Windows](https://ollama.com/download/windows). После установки запусти Ollama, если она не запустилась автоматически.
2. Открой **PowerShell** и скачай маленькую многоязычную модель (один раз):

   ```powershell
   ollama pull qwen3:0.6b
   ```

   Вес модели при загрузке — **около 523 МБ**. Вместе с Ollama она будет занимать больше места; при работе модели также потребуется оперативная память. Модель использует процессор, а при поддержке и наличии ресурсов — видеокарту.

3. Проверь работу модели:

   ```powershell
   ollama run qwen3:0.6b "Привет, как дела?"
   ```

4. Скачай `TeleType.exe` из GitHub Actions (см. следующий раздел), распакуй и запусти **обычным двойным щелчком**. Никаких API-ключей вводить не нужно. **Ollama должна быть запущена**.
5. Открой Telegram Desktop, начни писать сообщение и используй подсказку или исправление ошибок.

Для более качественного текста можно установить модель побольше:

```powershell
ollama pull qwen3:1.7b
$env:TELETYPE_MODEL = "qwen3:1.7b"
.\TeleType.exe
```

В этой настройке размер модели около **1,4 ГБ**, а нагрузка на память выше. По умолчанию используется `qwen3:0.6b`. Выбранная переменная действует для запущенного из той же консоли приложения.

## Где взять TeleType.exe

После публикации исходников в репозитории GitHub:

1. Открой вкладку **Actions**.
2. Выбери **Build TeleType for Windows** и последний успешный запуск.
3. Скачай артефакт **TeleType-Windows-x64**. Внутри будет `TeleType.exe`.

Быстрая сборка вручную на Windows с Visual Studio Build Tools (C++ Desktop) и CMake:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
```

Готовый файл: `build\Release\TeleType.exe`. Приложение написано на C++/Win32. Оно не содержит Python, Node.js, Electron, встроенных весов модели или Telegram-сессии.

## Размер и затраты

| Компонент | Размер / стоимость |
|---|---|
| `TeleType.exe` | небольшой нативный файл; точный размер покажет сборка Windows |
| Весы `qwen3:0.6b` | около **523 МБ** загрузки |
| Ollama | устанавливается отдельно, требует дополнительного места |
| Токены и запросы | **0 €**: всё выполняется на твоём компьютере |
| Интернет | нужен для первоначальной установки; не нужен для генерации |

Модель не является частью ZIP-архива или исходного GitHub-репозитория, чтобы сам проект оставался лёгким. При работе возможна задержка, особенно на слабом ноутбуке или при параллельном запуске игр.

## Важные ограничения и приватность

- **Только классический Telegram Desktop для Windows (`Telegram.exe`)**, не веб-версия, не мобильное приложение и не альтернативные Telegram-клиенты. Это **прототип, не протестированный на реальной Windows-машине**. Модель вызывается через API Ollama `/api/chat` с параметрами `stream:false`, `think:false`.
- Программа использует Win32 low-level keyboard hook: она отслеживает нажатия, **когда активен Telegram**, но пока не умеет достоверно отличать поле отправки сообщения от строки поиска или других полей. При наборе в другом поле подсказки могут быть неуместны. Нет доступа к аккаунту, переписке, чатам, истории сообщений или отправке сообщений.
- **Автоматическое продолжение** восстанавливает только то, что пользователь набрал при запущенном приложении. Вставка через буфер обмена, перемещение курсора, IME-ввод, изменение текста мышью и смена чатов могут сбросить или рассинхронизировать подсказку.
- **Исправление** выделяет и копирует весь черновик командой `Ctrl+A`, `Ctrl+C`; после чтения восстанавливает исходный буфер обмена. Команда должна запускаться только с фокусом в поле сообщения. Если Telegram не подтвердил новое копирование, программа не отправляет старый буфер на обработку.
- Для продолжения текст передаётся **только локальному** сервису `http://127.0.0.1:11434/api/chat`, а не в интернет. Установленный отдельно Ollama — самостоятельная программа со своими настройками; для гарантированной офлайн-работы используй **скачанную локальную** модель, а не cloud-модели Ollama.
- Ошибки в предложениях могут менять смысл: проверяй текст перед нажатием Ctrl+Alt+J. Изменение чата клавиатурой или нестандартным способом при выполнении запроса тоже может привести к неактуальной подсказке — не подтверждай её.
- Для предложения выдерживается минимум 4 секунды между запросами; одновременно выполняется не больше одного запроса. Если Ollama долго отвечает, новое предложение может не появляться до завершения старого.
- Клавиатурные хуки и подмена текста могут быть отмечены антивирусами и конфликтовать с другим софтом. Собирай из понятных исходников и проверяй поведение в Telegram на собственном компьютере.

## Как устроено

```text
Telegram Desktop (Windows)
     ↕ отслеживание ввода / Win32 SendInput
TeleType.exe (C++ / Win32)
     ↕ HTTP только по адресу 127.0.0.1:11434
Ollama (на том же ПК)
     ↕
qwen3:0.6b (локальная модель)
```

Код не пишет сообщения в файлы, не создаёт конфигов с секретами, не отправляет телеметрию. Отдельный backend или облачный сервер не нужен.

## Тестирование

Независимый от Windows тест парсера ответа Ollama и Unicode:

```bash
g++ -std=c++17 -Wall -Wextra -Werror tests/json_tests.cpp -o json_tests
./json_tests
```

GitHub Actions автоматически выполняет тесты на Ubuntu и собирает `.exe` на Windows. Тест парсера **не означает**, что интеграция с Telegram прошла end-to-end тестирование; для этого требуется реальный Windows и Telegram Desktop.

## English (quick start)

TeleType is an experimental lightweight Windows helper for Telegram Desktop. It provides short inline-style completions (**Ctrl+Alt+J** accepts) and spelling/grammar correction (**Ctrl+Alt+G** previews, **Ctrl+Alt+J** accepts). It runs **fully locally** via Ollama and Qwen3 0.6B. No paid API, API key, Telegram bot token, or account login is needed. Run `ollama pull qwen3:0.6b`, start Ollama, then start `TeleType.exe`. The helper is an overlay, not a native Telegram plugin. Windows/Telegram integration has not yet been tested end-to-end.
